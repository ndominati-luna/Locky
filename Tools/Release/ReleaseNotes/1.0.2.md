# Locky 1.0.2

- Cinq animations de verrouillage au choix : Iris, Halo, Envol (le logo arrive et repart comme un oiseau), Rideau, ou aucune.
- Le texte sous le logo apparaît de quatre façons, sur une couleur, le fond d'écran flouté ou une image de ton choix.
- L'animation se choisit aussi depuis l'iPhone, avec un aperçu, et le verrouillage automatique s'y met en pause ou s'y réactive.
- Les pochettes des morceaux écoutés en streaming dans Musique s'affichent sur l'iPhone Duo.
- L'iPhone signale les nouvelles versions de Locky pour Mac et ouvre la mise à jour sur le Mac.
- Les notes de toutes les versions sont dans le menu Locky, rubrique « Notes de version… ».
- La fin de l'apparition du texte de l'animation ne saute plus.
